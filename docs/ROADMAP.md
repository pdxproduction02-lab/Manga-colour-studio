# Roadmap

## V1
Upload → colorize → download.

## V2
Drag/drop, before/after slider, palettes, batch pages, progress jobs, PNG/WebP, 2x upscale.

## V3
Panel detection, speech-bubble protection, screentone detection, character reference sheets, project palettes, region repaint.

## V4
GPU worker, Redis queue, object storage, authentication, volume-level consistency, tiled inference.

## V5
Fine-tuned manga-specific model, reference conditioning, multi-page identity consistency, layer export, professional colorist controls.
